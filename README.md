# Проект REINFORCE с GAE и Baseline на PyBullet

### 🎮 Обучение агента с использованием алгоритма REINFORCE с адаптивным baseline и GAE
* 🖥️ **Технологии**: Python, PyTorch, Gym, PyBullet, NumPy, Matplotlib, Threading

🔹 **Описание**: В этом проекте реализовано обучение агента в среде `InvertedPendulumPyBulletEnv-v0` с использованием алгоритма REINFORCE, добавлением адаптивного baseline (Value Network) и Generalized Advantage Estimation (GAE). Это улучшает стабильность и ускоряет обучение по сравнению с классическим REINFORCE.

### 🧑‍💻 Достижения:
* ✅ **Многопоточность**: Использовано 4 потока для параллельного сбора данных
* ✅ **Реализация различных конфигураций**: Протестировано 4 варианта алгоритма REINFORCE (с baseline, с GAE и с их комбинацией)
* ✅ **Использование TimeLimit** для ограничения шагов на эпизод
* ✅ **Обучение на 800 эпизодах на поток**, с лимитом в 500 шагов на эпизод
* ✅ **Графики обучения и сравнение конфигураций**

### 🔹 Результаты:
На основе проведённых экспериментов с четырьмя конфигурациями (REINFORCE, REINFORCE + baseline, REINFORCE + GAE, REINFORCE + baseline + GAE) были получены следующие результаты:

1. **Результаты конфигурации A: REINFORCE**
   - Среднее вознаграждение: 8.8
   - Максимум: 39
   - Стандартное отклонение: 2.6
   - **Анализ**: Без использования baseline обучение не стабилизируется, что приводит к крайне низкому и нетерпимому вознаграждению.

2. **Результаты конфигурации B: REINFORCE + baseline**
   - Среднее вознаграждение: 974.1
   - Максимум: 1500
   - Стандартное отклонение: 654.8
   - **Анализ**: Использование baseline значительно улучшает обучение, обеспечивая стабильное достижение высокого вознаграждения и его быстрое достижение.

3. **Результаты конфигурации C: REINFORCE + GAE**
   - Среднее вознаграждение: 9.1
   - Максимум: 36
   - Стандартное отклонение: 2.6
   - **Анализ**: Использование GAE без baseline не даёт значительных улучшений, так как преимущества не имеют корректной «опорной линии» для обучения.

4. **Результаты конфигурации D: REINFORCE + baseline + GAE**
   - Среднее вознаграждение: 879.1
   - Максимум: 1500
   - Стандартное отклонение: 647.7
   - **Анализ**: Сочетание baseline и GAE улучшает стабильность, но обучение идёт медленно по сравнению с конфигурацией B. Время достижения максимума увеличивается из-за дополнительных вычислений.

### 🧑‍💻 График обучения:
* Визуализация скользящего среднего вознаграждения по эпизодам с оконной функцией на 100 эпизодов для каждой конфигурации.

### 🔹 Анализ вычислительной эффективности:
* Общее количество взаимодействий: 4 потока × 800 эпизодов × 500 шагов = 1 600 000 взаимодействий.
* Среднее время на эпизод (при оптимальной настройке) значительно отличается между конфигурациями, где более сложные модели требуют больше вычислительных ресурсов.

### 📊 Выводы и рекомендации:
1. **Адаптивный baseline** значительно улучшает результаты. Без него обучение остаётся неэффективным.
2. **Использование GAE** полезно только в связке с baseline. Самостоятельно GAE не даёт преимущества.
3. **Для лучшей эффективности** рекомендуется использовать **REINFORCE с baseline** (Конфигурация B) для достижения стабильных и быстрых результатов.
4. **Дальнейшие улучшения**:
   - Увеличение лимита шагов на эпизод и числа эпизодов для более детального анализа.
   - Эксперименты с гиперпараметрами GAE (λ, γ) для улучшения результатов.
   - Использование **асинхронной архитектуры** для разделения акторов и обучающих агентов, что ускорит процесс обновления параметров.
