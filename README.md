# REINFORCE с GAE и адаптивным baseline в PyBullet

Этот репозиторий содержит реализацию и подробное исследование алгоритма REINFORCE с адаптивной базовой линией (Value Network) и Generalized Advantage Estimation (GAE) на среде **InvertedPendulumPyBulletEnv-v0** из `pybullet-gym`. Мы провели абляционное исследование четырёх конфигураций, проанализировали качество обучения и вычислительную эффективность.

## 📝 Введение

REINFORCE — базовый полносеточный стохастический алгоритм градиентного обучения политики.  
**Цель проекта**:  
- Добавить **адаптивный baseline** (Value Network)  
- Внедрить **GAE** для улучшения оценки преимущества  
- Протестировать на PyBullet-среде `InvertedPendulumPyBulletEnv-v0`  
- Провести **абляционное исследование** и **анализ вычислительной эффективности**

---

## 🧪 Конфигурации экспериментов

Сравнение четырех вариантов:
* A: REINFORCE
* B: REINFORCE + adaptive baseline
* C: REINFORCE + GAE
* D: REINFORCE + adaptive baseline + GAE

Каждая конфигурация обучалась в 4 потоках, по 800 эпизодов на поток, 500 шагов на эпизод.
